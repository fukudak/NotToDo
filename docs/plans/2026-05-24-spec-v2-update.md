# 2026-05-24 spec-v2更新とプラン矛盾解消

## 目的

spec-v1.mdはBun/Honoサーバー+JSONファイル永続化を想定して書かれていたが、実際のコードは完全にクライアントサイド（React SPA + localStorage）に移行済みだった。仕様書とコードが乖離していた状態を解消する。

## 変更

### spec-v2.md 作成

- サーバー/JSONファイルの記述を完全に削除
- React SPA + localStorage + クライアント関数の動作に全面合わせ
- データモデルに `userId` / `completedAt` / `plan` / `maxItems` を反映
- コンポーネント一覧（10種類）、カスタムフック（3種類）、ストレージ層を記載
- 仕様上の矛盾を明記（UpgradePromptは「エクスポート不可」だが DataManager にエクスポートボタンが実在）

### 仕様矛盾（課金/プラン）

| 問題 | 対応 |
|------|------|
| UpgradePrompt 「エクスポート不可」 | →「エクスポート可」に修正 |
| UpgradePrompt 「エクスポート/インポート」を有料特典として記載 | →「クラウド同期（将来）」に変更 |
| DataManager に無料版でのエクスポートガードなし（実際は可能） | 仕様側を現状に合わせて解消 |

課金実装（Stripe）が未実装なので、「エクスポート無料」を仕様として確定した。
