# NotToDo UIリデザイン計画

**日付**: 2026-06-15
**目的**: 現在のUIがイマイチなので、Fluent 2と現代的なタスク管理アプリを参考にデザインを刷新する

---

## 1. 現在の問題点（推定）

- 全体的に情報密度が高く、視覚的に疲れる
- 「やらないこと」というネガティブなテーマに対して、UIが硬い
- Fluent 2のようなモダンで落ち着いたデザイン言語が不足
- カードやリストの階層・余白が不十分
- レビュー画面や設定画面の体験が弱い

---

## 2. 参考ソース

### 2.1 Fluent 2 Design System
- https://fluent2.microsoft.design/
- 推奨する方向性:
  - タイポグラフィ（Segoe UI系）
  - Spacing（8pxベース）
  - Color tokens（Neutral, Brand）
  - Card / List / Button のコンポーネント言語

### 2.2 現代的なタスク管理UI参考
- Todoist / Linear / Notion / Things 3 のようなクリーンで階層的なデザイン
- カードの微妙なシャドウとボーダー
- ステータスを色とアイコンで軽やかに表現
- 余白を活かした「余裕のある」印象

---

## 3. デザイン方向性

### 3.1 全体トーン
- 「やらないこと」を前向きに受け止めるための、**落ち着いた・優しい・クリーン**な印象
- グリーンは避け、**落ち着いたブルーグレー / ウォームグレー / ソフトパープル** などの落ち着いたアクセントカラーを検討

### 3.2 主要変更点

| 部分           | 現在の問題             | 改善案                              |
|----------------|------------------------|-------------------------------------|
| ItemCard       | 情報が詰まりすぎ       | 余白を増やし、理由を折りたたみ可能に |
| ItemList       | 視覚的な区切りが弱い   | Fluent風のリストスタイルに刷新     |
| ReviewPanel    | 振り返り体験が弱い     | より読みやすいタイムライン形式     |
| 全体カラー     | 硬い印象               | Neutral + アクセントカラーのバランス |

---

## 4. 実装ステップ（提案）

### Phase 1: ベース整備
1. Fluent 2のカラートークンとタイポグラフィをTailwindに導入
2. 基本的なCard/Listコンポーネントを刷新
3. Spacingと余白ルールを統一

### Phase 2: ItemCardの改善
1. 理由部分を折りたたみ可能にする
2. 優先度・作成日などのメタ情報を整理して表示
3. ホバー/タップ時のフィードバックを強化

### Phase 3: リスト全体の体験向上
1. ドラッグ&ドロップの視覚的フィードバック改善
2. 空状態のデザインを魅力的に
3. フィルタ・ソートUIの刷新

### Phase 4: Review / Settingsの改善
1. ReviewPanelをタイムライン風に
2. Settingsをよりモダンなフォームに
